Xarc
====

Xarc is an operating system built around one idea:

"You own the technology. You decide how it works."

Xarc aims to provide a familiar computing experience while
giving users progressively deeper control over their system.

PROJECT STATUS
--------------

Xarc is currently in early development.

Current work:
- Bootable Xarc ISO
- Xarc Terminal
- AD System
- Xarc Desktop
- Xarc Flow
